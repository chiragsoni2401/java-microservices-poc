# 🚀 Complete Setup Guide - Java Microservices POC\n\n## Prerequisites\n\n- **Java 21+** - [Download](https://www.oracle.com/java/technologies/downloads/)\n- **Maven 3.8+** - [Download](https://maven.apache.org/download.cgi)\n- **Docker Desktop** - [Download](https://www.docker.com/products/docker-desktop)\n- **Git** - [Download](https://git-scm.com/)\n- **Postman/Curl** - For API testing\n\n---\n\n## 📂 Project Structure Setup\n\n```bash\n# Create root directory structure\nmkdir -p java-microservices-poc/{order-service,notification-service,kubernetes,docs,scripts}\n\ncd java-microservices-poc\n\n# Create Maven module structure for order-service\nmkdir -p order-service/src/main/java/com/ecommerce/order/{controller,service,repository,entity,dto,event,config}\nmkdir -p order-service/src/main/resources\nmkdir -p order-service/src/test/java/com/ecommerce/order\n\n# Create Maven module structure for notification-service\nmkdir -p notification-service/src/main/java/com/ecommerce/notification/{service,event,config}\nmkdir -p notification-service/src/main/resources\nmkdir -p notification-service/src/test/java/com/ecommerce/notification\n```\n\n---\n\n## 📝 Step 1: Create Order Service pom.xml\n\n**File**: `order-service/pom.xml`\n\nCopy the pom.xml content provided in the main README or from the source files.\n\n---\n\n## 📝 Step 2: Create Java Classes for Order Service\n\n### OrderServiceApplication.java\n**Path**: `order-service/src/main/java/com/ecommerce/order/OrderServiceApplication.java`\n\n```java\npackage com.ecommerce.order;\n\nimport org.springframework.boot.SpringApplication;\nimport org.springframework.boot.autoconfigure.SpringBootApplication;\nimport org.springframework.cloud.client.discovery.EnableDiscoveryClient;\nimport org.springframework.kafka.annotation.EnableKafka;\n\n@SpringBootApplication\n@EnableDiscoveryClient\n@EnableKafka\npublic class OrderServiceApplication {\n    public static void main(String[] args) {\n        SpringApplication.run(OrderServiceApplication.class, args);\n    }\n}\n```\n\n### OrderEntity.java\n**Path**: `order-service/src/main/java/com/ecommerce/order/entity/OrderEntity.java`\n\nRefer to the entity file in the project files.\n\n### OrderDTO.java\n**Path**: `order-service/src/main/java/com/ecommerce/order/dto/OrderDTO.java`\n\nRefer to the DTO file in the project files.\n\n### OrderRepository.java\n**Path**: `order-service/src/main/java/com/ecommerce/order/repository/OrderRepository.java`\n\nRefer to the repository file in the project files.\n\n### OrderService.java\n**Path**: `order-service/src/main/java/com/ecommerce/order/service/OrderService.java`\n\nRefer to the service file in the project files.\n\n### OrderController.java\n**Path**: `order-service/src/main/java/com/ecommerce/order/controller/OrderController.java`\n\nRefer to the controller file in the project files.\n\n### KafkaConfig.java\n**Path**: `order-service/src/main/java/com/ecommerce/order/config/KafkaConfig.java`\n\nRefer to the config file in the project files.\n\n---\n\n## ⚙️ Step 3: Create application.yml\n\n**File**: Compose\n\n**File**: `docker-compose.yml`\n\nRefer to the docker-compose.yml file in the project files.\n\n---\n\n## 📊 Step 7: Create Prometheus Config\n\n**File**: `prometheus.yml`\n\nRefer to the prometheus.yml file in the project files.\n\n---\n\n## 🔧 Build Instructions\n\n### Build Order Service\n```bash\ncd order-service\nmvn clean package -DskipTests\ncd ..\n```\n\n### Build Notification Service\n```bash\ncd notification-service\nmvn clean package -DskipTests\ncd ..\n```\n\n### Build All Services\n```bash\nmvn clean package -DskipTests -pl order-service,notification-service\n```\n\n---\n\n## 🚀 Running the Application\n\n### Start All Services\n```bash\ndocker-compose up -d\n```\n\n### Check Status\n```bash\n# List running containers\ndocker-compose ps\n\n# View logs\ndocker-compose logs -f\n\n# View specific service logs\ndocker-compose logs -f order-service\ndocker-compose logs -f notification-service\n```\n\n### Stop All Services\n```bash\ndocker-compose down\n```\n\n### Clean Up Volumes\n```bash\ndocker-compose down -v\n```\n\n---\n\n## 🧪 Testing APIs\n\n### Create Order\n```bash\ncurl -X POST http://localhost:8080/api/v1/orders \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"customerId\": \"CUST-001\",\n    \"productId\": \"PROD-123\",\n    \"quantity\": 2,\n    \"totalPrice\": 99.99\n  }'\n```\n\n### Get Order\n```bash\ncurl http://localhost:8080/api/v1/orders/{orderId}\n```\n\n### Health Check\n```bash\ncurl http://localhost:8080/api/v1/orders/health\n```\n\n---\n\n## 📊 Accessing Dashboards\n\n- **Eureka Server**: http://localhost:8761\n- **Prometheus**: http://localhost:9090\n- **Grafana**: http://localhost:3000 (admin/admin)\n- **Order Service**: http://localhost:8080\n- **Notification Service**: http://localhost:8081\n\n---\n\n## 🔍 Troubleshooting\n\n### Port Already in Use\n```bash\n# Kill process on port 8080\nlsof -ti:8080 | xargs kill -9\n\n# Or change port in application.yml\nserver:\n  port: 8085\n```\n\n### Docker Issues\n```bash\n# Clean up all Docker resources\ndocker system prune -a\n\n# Rebuild images\ndocker-compose build --no-cache\n```\n\n### Kafka Connection Issues\n```bash\n# Check Kafka broker\ndocker exec kafka kafka-broker-api-versions.sh --bootstrap-server localhost:9092\n\n# List topics\ndocker exec kafka kafka-topics.sh --list --bootstrap-server localhost:9092\n```\n\n---\n\n## ✨ Next Steps\n\n1.
